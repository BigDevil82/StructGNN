# 强化学习在剪力墙结构优化中的状态表征设计


## 图结构设计方案

### 3.1 推荐：双层级图（Hierarchical Graph）

```
【构件层图】                    【楼层层图】
每个构件 = 节点                每层 = 聚合节点
层内连接 = 同层构件共节点       层间连接 = 上下楼层关系
层间连接 = 竖向构件跨层         全局节点 = 整体结构摘要
```

具体实现：

```
G = (V_member, V_floor, V_global, E_member, E_floor, E_vertical)

V_member: 每个构件节点（墙段/连梁）
V_floor:  每层聚合节点（层刚度、层剪力等）
V_global: 1个全局节点（周期、总质量等）

E_member:  同层构件之间（共享节点/相邻关系）
E_floor:   构件 → 所属楼层（从属关系）
E_vertical: 上下层同位置墙肢之间（竖向连续性）
```

消息传递路径：
```
构件节点 → 楼层节点 → 全局节点
             ↓
        楼层节点间（上下层）
             ↓
        全局节点 → 楼层节点 → 构件节点（反向传播全局信息）
```

### 3.2 标准层的处理：参数共享 + 位置区分

对于完全相同的标准层，可以：
- **共享 GNN 权重**（同一类型构件用同一套参数）
- **用楼层位置编码区分**（类似 Transformer 的 positional encoding）

```python
# 楼层位置编码（相对高度 + 绝对层号）
floor_pos_encoding = [
    floor_idx / total_floors,          # 相对高度 0~1
    floor_height / total_height,       # 相对标高
    axial_load_ratio_floor,            # 该层重力荷载占比
    seismic_shear_ratio_floor,         # 该层地震剪力占比
]
```

这样即使平面布置相同，每层构件的节点特征因位置编码不同而不同，GNN 可以学到"底层墙要更保守"的规律。

## 四、节点特征组成

### 构件节点特征（墙/梁分开）

**剪力墙节点**：
```
几何特征:    [长度, 厚度, 截面面积, 惯性矩]
位置特征:    [层号/总层数, 层高/总高, X坐标/总宽, Y坐标/总长]
力学响应:    [轴力, 水平剪力, 弯矩, 轴压比, 剪压比]
当前截面:    [截面编号(嵌入), 配筋率, 含钢量]
约束状态:    [轴压比裕度, 剪压比裕度, 配筋率裕度]  ← 关键！
```

**连梁节点**：
```
几何特征:    [跨度, 截面高度, 宽度]
位置特征:    [层号/总层数, 连接的左墙ID, 连接的右墙ID]
力学响应:    [剪力, 弯矩, 剪压比]
约束状态:    [剪压比裕度, 配筋率裕度]
```

### 边特征

```
同层连接边:  [相对位置, 是否共节点, 连接类型(梁-墙/墙-墙)]
竖向连接边:  [层间距, 是否同一墙肢, 截面变化量]
构件-楼层边: [从属关系, 该构件刚度贡献占楼层比例]
```

### 楼层节点特征

```
[层高, 层质量, 层侧向刚度, 层间位移角, 层剪力, 层倾覆弯矩,
 层号/总层数, 与嵌固端距离/总高]
```

### 全局节点特征

```
[结构总高, 总层数, 第1~3自振周期, 基底剪力,
 最大层间位移角及其位置, 总材料用量, 可行性标志]
```

