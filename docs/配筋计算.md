# 目标

本模块旨在根据有限元分析得到的内力结果，按照国家规范进行梁和剪力墙的配筋计算及校核，并统计材料用量，为结构优化设计提供准确的输入数据。

荷载组合取：1.2×(恒+0.5活) + 1.3×水平地震作用，计算构件内力用于配筋设计。

在所有构件达到适筋要求的前提下，优化目标为最小化结构总材料用量（混凝土+钢筋），同时满足抗震设计规范的安全要求。

若某构件配筋不满足规范要求，主要是超筋（少筋可按构造配筋），需返回该构件不合格，以触发优化算法调整设计变量（如截面尺寸、混凝土强度等级等）。

## 统一约定

1. 抗震等级：二级
2. 钢筋等级：HRB400
3. 纵向钢筋合力点到截面受拉边缘距离：40mm

# 二、通用基础参数（固定取值）

## 2.1 材料参数

| 材料类型 | 参数名称               | 符号 | 默认值（MPa） | 说明                        |
| -------- | ---------------------- | ---- | ------------- | --------------------------- |
| 混凝土   | 轴心抗压强度设计值     | f_c  | 14.3（C30）   | C30~C50常用，代码可设为变量 |
| 混凝土   | 轴心抗拉强度设计值     | f_t  | 1.43（C30）   | 与混凝土强度等级对应        |
| 钢筋     | 纵向钢筋抗拉强度设计值 | f_y  | 400（HRB400） | 主力钢筋，可替换为HRB500    |
| 钢筋     | 箍筋抗拉强度设计值     | f_yv | 400（HRB400） | 箍筋、拉筋通用              |

## 2.2 抗震与规范参数（固定取值，适配抗震设计）

| 参数名称                       | 符号 | 取值                       | 适用场景               |
| ------------------------------ | ---- | -------------------------- | ---------------------- |
| 受压区高度系数限值（超筋判断） | ξ_b  | 0.518（HRB400）            | 梁、剪力墙边缘构件受弯 |
| 承载力调整系数                 | γ_RE | 0.75（受弯）；0.85（受剪） | 抗震设计通用           |
| 混凝土受压系数                 | α₁   | 1.0（C50及以下）           | 正截面受弯、受压计算   |
| 混凝土强度影响系数             | β_c  | 1.0（C50及以下）           | 斜截面受剪截面验算     |

## 2.3 密度参数（用于材料用量计算）

混凝土密度 ρ_conc = 25 kN/m³（即2500 kg/m³）；钢筋密度 ρ_steel = 78.5 kN/m³（即7850 kg/m³）

# 三、梁配筋计算及校核

## 3.1 计算前提（每个梁构件单独提取）

输入参数：梁截面尺寸（b：梁宽，h：梁高）、梁长度l；最不利内力（跨中+M_max、支座-M_max、全梁V_max）；抗震等级（默认二级）。

计算有效高度 h₀ = h - a_s（a_s：纵向钢筋合力点到截面受拉边缘距离，默认取40mm，代码可设为常量）。

## 3.2 正截面受弯配筋计算（纵筋：梁顶/梁底）

### 3.2.1 计算步骤

1. 计算相对受压区高度系数 α_s： $\alpha_s = \frac{\gamma_{RE} \cdot M}{\alpha_1 f_c b h_0^2}$ 

2. 计算内力臂系数 γ_s： $\gamma_s = 0.5 \times (1 + \sqrt{1 - 2\alpha_s})$ （若1-2α_s<0，判定为超筋）

3. 计算纵向钢筋面积 A_s： $A_s = \frac{\gamma_{RE} \cdot M}{\gamma_s f_y h_0}$ 

### 3.2.2 超筋、少筋校核
1. 超筋校核：计算受压区高度 ξ = α_s / α₁，若 ξ > ξ_b → 超筋（不安全，需增大梁截面或提高混凝土强度）；

2. 少筋校核：梁最小纵筋配筋率 ρ_min = 0.2%（抗震二级），最小纵筋面积 A_s,min = ρ_min × b × h₀；若 A_s < A_s,min → 少筋（不满足规范，取 A_s = A_s,min）；

3. 合格判定：A_s,min ≤ A_s ≤ A_s,max（A_s,max = α₁ f_c b h₀ ξ_b / f_y）。

## 3.3 斜截面受剪配筋计算（箍筋）

### 3.3.1 计算步骤

1. 截面验算（先判断截面是否足够）： $V \leq \frac{1}{\gamma_{RE}} \times 0.25 \beta_c f_c b h_0$ ；若不满足，需增大梁截面（代码返回“截面不足”）；

2. 计算箍筋配筋率比 A_sv/s： $\frac{A_{sv}}{s} = \frac{\gamma_{RE} \cdot V - 0.7 f_t b h_0}{f_{yv} h_0}$ （若分子<0，按构造配箍）；

3. 确定箍筋参数：采用双肢箍（A_sv = 2×A_d，A_d为单肢箍筋面积，如Φ8→A_d=50.3mm²），计算箍筋间距 s = A_sv / (A_sv/s)。

### 3.3.2 箍筋校核（代码判断条件）

1. 最小配箍率：ρ_sv,min = 0.24 f_t / f_yv （根据实际计算）；

2. 最小箍筋面积比：(A_sv/s)_min = ρ_sv,min × b；若 (A_sv/s) < (A_sv/s)_min → 按构造配箍，取 (A_sv/s) = (A_sv/s)_min；

3. 箍筋间距限值：梁端加密区 s ≤ 100mm，非加密区 s ≤ 200mm（代码可设为约束条件）。

## 3.4 梁材料用量计算（单个梁构件）

1. 混凝土用量： $V_{beam} = b \times h \times l$ ，重量  $W_{conc,beam} = V_{beam} \times \rho_{conc}$ ；

2. 纵筋重量： $W_{s,long} = (A_{s,top} + A_{s,bot}) \times l \times \rho_{steel} \times 10^{-6}$ （A_s单位：mm²，l单位：m，换算为m³后乘密度）；

3. 箍筋重量： $W_{s,stir} = A_{sv} \times \frac{l}{s} \times (h - 2 \times a_s) \times \rho_{steel} \times 10^{-6}$ （h-2a_s为箍筋有效高度）；

4. 单个梁总材料重量： $W_{beam,total} = W_{conc,beam} + W_{s,long} + W_{s,stir}$ 。

# 四、剪力墙配筋计算及校核（墙身+边缘构件）

## 4.1 计算前提（每个墙肢单独提取）

输入参数：墙肢截面（b_w：墙厚，l_w：墙长）、楼层高度h_story；最不利内力（N：轴力，M：弯矩，V：剪力）；抗震等级、轴压比n；底部加强区标识（判断边缘构件类型）。

计算有效高度 h₀ = l_w - a_s（a_s默认取40mm，墙肢纵向钢筋合力点距离）。

## 4.2 墙身分布筋计算及校核（竖向+水平）

### 4.2.1 竖向分布筋（抗侧压弯，按每米墙宽计算）

1. 计算步骤：按偏心受压构件计算所需竖向钢筋面积A_s,vert，实际工程中多由最小配筋率控制；

2. 最小配筋率（抗震）：一级≥0.25%，二~四级≥0.20%（代码可按抗震等级取对应值）；

3. 每米墙宽竖向筋面积： $A_{s,vert,per_m} = max\left( \text{计算值}, \rho_{min,vert} \times b_w \times 1000 \right)$ （1000mm为1米墙宽）；

4. 校核：A_s,vert,per_m ≥ ρ_min,vert × b_w × 1000 → 满足少筋要求，无超筋（分布筋不控制超筋）。

### 4.2.2 水平分布筋（抗剪，按每米墙宽计算）

1. 计算步骤： $A_{s,hor} = \frac{(\gamma_{RE} \cdot V - 0.4 f_t b_w h_0) \times s}{0.8 f_{yh} h_0}$ （s为水平筋间距，默认200mm，可设为变量）；

2. 最小配筋率（抗震）：≥0.20%（不分等级）；

3. 每米墙宽水平筋面积： $A_{s,hor,per_m} = max\left( \frac{A_{s,hor}}{s} \times 1000, \rho_{min,hor} \times b_w \times 1000 \right)$ ；

4. 校核：水平筋间距s ≤ 200mm（抗震），A_s,hor,per_m ≥ 最小面积 → 合格。

## 4.3 边缘构件配筋计算及校核（暗柱/端柱，每个墙肢端部单独计算）

### 4.3.1 第一步：判断边缘构件类型

| 抗震等级 | 底部加强区（轴压比n） | 非底部加强区（轴压比n） | 构件类型     |
| -------- | --------------------- | ----------------------- | ------------ |
| 一级     | n > 0.2               | n > 0.3                 | 约束边缘构件 |
| 二~四级  | n > 0.3               | n > 0.4                 | 约束边缘构件 |
| 所有等级 | n ≤ 对应限值          | n ≤ 对应限值            | 构造边缘构件 |

### 4.3.2 第二步：纵筋计算及校核（对称配筋）

1. 计算步骤：按偏心受压构件计算， $x = \frac{\gamma_{RE} \cdot N}{\alpha_1 f_c b_c}$ （b_c为边缘构件截面宽度，默认取墙厚b_w或按规范经验值取）；

2. 大偏心判定（x ≤ ξ_b）： $A_s = \frac{\gamma_{RE} \cdot M - \alpha_1 f_c b_c x (h_0 - x/2)}{\gamma_s f_y (h_0 - a_s')}$ （a_s' = a_s = 40mm）；

3. 小偏心判定（x > ξ_b）：按小偏心公式计算（代码可简化，优先按大偏心计算，小偏心时返回“需增大截面”）；

4. 校核：
       

   - 少筋：A_s ≥ 最小纵筋面积（约束边缘构件≥0.8%×b_c×h_c，构造边缘构件≥0.5%×b_c×h_c，h_c为边缘构件高度）；

   - 超筋：x ≤ ξ_b，否则超筋（需增大边缘构件截面）。

### 4.3.3 第三步：箍筋计算及校核（约束边缘构件需计算，构造边缘构件按构造）

1. 约束边缘构件：按体积配箍率计算，体积配箍率ρ_v ≥ 0.8%（一级）、0.6%（二级）、0.4%（三~四级）；

2. 箍筋面积计算： $\rho_v = \frac{A_{sv} \times s_c}{b_c \times h_c \times s}$ （s_c为箍筋肢距，默认100mm），解出A_sv；

3. 校核：箍筋间距s ≤ 100mm（约束边缘构件）、s ≤ 150mm（构造边缘构件），配箍率满足最小要求。

## 4.4 剪力墙材料用量计算（单个墙肢）

1. 混凝土用量： $V_{wall} = b_w \times l_w \times h_{story}$ ，重量  $W_{conc,wall} = V_{wall} \times \rho_{conc}$ ；

2. 墙身竖向分布筋重量： $W_{s,vert} = A_{s,vert,per_m} \times l_w \times h_{story} \times \rho_{steel} \times 10^{-6}$ （l_w为墙长，换算为米）；

3. 墙身水平分布筋重量： $W_{s,hor} = A_{s,hor,per_m} \times h_{story} \times \rho_{steel} \times 10^{-6}$ （每米墙宽，乘墙长l_w）；

4. 边缘构件钢筋重量： $W_{s,boundary} = (A_{s,long} \times h_c + A_{sv} \times \frac{h_c}{s} \times b_c) \times \rho_{steel} \times 10^{-6}$ （每个边缘构件，墙肢有2个端部，需乘2）；

5. 单个墙肢总材料重量： $W_{wall,total} = W_{conc,wall} + W_{s,vert} + W_{s,hor} + W_{s,boundary}$ 。

# 五、整体材料用量统计

1. 遍历所有梁构件，汇总单个梁的W_beam,total → 总梁材料重量W_beam_all；

2. 遍历所有墙肢构件，汇总单个墙肢的W_wall,total → 总剪力墙材料重量W_wall_all；

3. 结构总材料重量（优化目标函数）： $W_{total} = W_{beam_all} + W_{wall_all}$ ；

4. 补充：可单独统计混凝土总重量、钢筋总重量，用于优化目标的细分（如同时优化重量和造价）。

# 六、代码实现注意事项

1. 遍历逻辑：按“构件类型（梁/墙肢）→ 单个构件 → 提取内力+尺寸 → 配筋计算 → 校核 → 材料用量”的顺序编写循环；

3. 约束判定：代码中需加入“超筋/少筋/截面不足”的判断，若不满足，直接返回该构件不合格，触发优化算法的变量更新；

4. 单位统一：所有参数单位统一（mm→m，mm²→m²），避免计算错误（如A_s单位mm²，需乘以10^-6转换为m²）。
