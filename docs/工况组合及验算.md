
### 第一部分：核心工况组合列表 (`combinations` 字典)

基本工况有：恒载(`Dead`)、活载(`Live`)、X向风(`WindX`)、Y向风(`WindY`)、X向地震(`EqX`)、Y向地震(`EqY`)，其中地震效应通过RSA计算得到。工况组合定义为如下列表字典：

```python
# load_combinations.py

COMBINATIONS = [
    # ==========================================
    # 类别 A: 非抗震基本组合 (用于风载主导的验算)
    # 活载组合值系数取 0.7 (即 1.5 * 0.7 = 1.05)
    # ==========================================
    # 1. 恒活为主
    {'name': '1.3D+1.5L', 'type': 'NonSeismic', 'factors': {'Dead': 1.3, 'Live': 1.5}},
    
    # 2. 考虑风载 (双向正负考虑)
    {'name': '1.3D+1.05L+1.5WX', 'type': 'NonSeismic', 'factors': {'Dead': 1.3, 'Live': 1.05, 'WindX': 1.5}},
    {'name': '1.3D+1.05L-1.5WX', 'type': 'NonSeismic', 'factors': {'Dead': 1.3, 'Live': 1.05, 'WindX': -1.5}},
    {'name': '1.3D+1.05L+1.5WY', 'type': 'NonSeismic', 'factors': {'Dead': 1.3, 'Live': 1.05, 'WindY': 1.5}},
    {'name': '1.3D+1.05L-1.5WY', 'type': 'NonSeismic', 'factors': {'Dead': 1.3, 'Live': 1.05, 'WindY': -1.5}},

    # ==========================================
    # 类别 B: 地震作用组合 (抗震设计的核心)
    # 重力荷载代表值 G = 1.0D + 0.5L
    # 组合公式: 1.2G ± 1.3E -> 即 1.2D + 0.6L ± 1.3E
    # ==========================================
    # 3. 考虑水平地震
    {'name': '1.2G+1.3EX', 'type': 'Seismic', 'factors': {'Dead': 1.2, 'Live': 0.6, 'EqX': 1.3}},
    {'name': '1.2G-1.3EX', 'type': 'Seismic', 'factors': {'Dead': 1.2, 'Live': 0.6, 'EqX': -1.3}},
    {'name': '1.2G+1.3EY', 'type': 'Seismic', 'factors': {'Dead': 1.2, 'Live': 0.6, 'EqY': 1.3}},
    {'name': '1.2G-1.3EY', 'type': 'Seismic', 'factors': {'Dead': 1.2, 'Live': 0.6, 'EqY': -1.3}},
]
```

### 第二部分：构件级指标验算逻辑与对应工况

#### 1. 轴压比验算 (仅剪力墙)
* **工程意义：** 规范中的轴压比限值（如 0.5、0.6）是一个**抗震构造概念**，目的是限制墙肢的轴心压力，确保在地震发生时剪力墙具有足够的塑性变形能力（延性）。
* **计算公式：** $\mu = N_{max} / (f_c \cdot A_c)$
* **对应工况（核心）：** **仅在“地震组合”（`type: 'Seismic'`）中寻找最大轴压力 $N_{max}$**。如果在非地震区，则在所有“非抗震基本组合”中找最大压力。
* **代码提取逻辑：**
    1. 遍历 `COMBINATIONS` 中 `type == 'Seismic'` 的所有组合。
    2. 对于某个特定的墙肢，提取它在这些组合下的轴力 $N$。
    3. 找出**最大压应力对应的轴力** $N_{max}$（注意在 OpenSees 中受压通常为负，所以是用 `min()` 找负得最多的值，然后取绝对值）。
    4. 用这个 $N_{max}$ 除以 $(f_c \cdot A_c)$ 计算轴压比。

#### 2. 剪压比验算 (剪力墙和连梁)
* **工程意义：** 限制截面尺寸，防止剪力过大导致混凝土过早发生斜压脆性破坏（不管配多少抗剪钢筋都没用）。
* **计算公式：**
    * 抗震工况下限值：$V_{max} \le 0.15 \beta_c f_c b h_0$
    * 非抗震工况下限值：$V_{max} \le 0.20 \beta_c f_c b h_0$ (注意系数不同)
    * 我们常说的剪压比就是指 $V_{max} / (\beta_c f_c b h_0)$。
* **对应工况（核心）：** **所有组合（包含非抗震和地震组合）**都要参与包络。
* **代码提取逻辑：**
    1. 遍历**所有**组合，提取该墙肢最大的剪力绝对值 $|V_{x, max}|$。
    2. 如果产生 $|V_{x, max}|$ 的组合属于 `Seismic`，则用抗震限值（0.15）去验算它；如果是 `NonSeismic`，则用非抗震限值去验算。
