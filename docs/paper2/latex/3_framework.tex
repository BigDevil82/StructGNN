\section{Calibrated Surrogate-Informed Optimization}
\label{sec:optimization_framework}

CASIO inserts a surrogate-informed candidate-selection layer between the search algorithm and the true structural evaluator. This decoupled interface allows the framework to operate with different optimizers while maintaining unified screening, ranking, and online calibration rules.

\subsection{Evaluation Loop}
\label{subsec:overall_framework}

Fig.~\ref{fig:calibrated_optimization_framework} and Algorithm~\ref{alg:csa_optimization} summarize the CASIO evaluation loop. At iteration $t$, the optimizer proposes a candidate batch $\mathcal{B}_t$ after enforcing discrete parameter bounds and nonincreasing wall thicknesses along the building height. Each candidate is encoded via $z=(G,d,q)$ and evaluated by the current surrogates to obtain $p_t$ and $m_t$, falling back to the global predictions whenever a local calibrator has not yet met its activation condition.

Based on these predictions, feasibility screening and cost-oriented ranking select a high-priority subset $\mathcal{A}_t \subseteq \mathcal{B}_t$ for true structural evaluation. Cached results are reused for previously visited designs, whereas new evaluations provide verified feasibility labels, material quantities, and constraint violations. These records are returned to the optimizer and appended to the local archive $\mathcal{D}_t$ to update the calibration models prior to the next iteration.


\begin{algorithm}[htbp]
\caption{CASIO evaluation loop}
\label{alg:csa_optimization}
\begin{algorithmic}[1]
\REQUIRE Fixed layout and conditions; design space; optimizer; global models $\Phi_f,\Phi_s$; structural evaluator; screening and selection settings; iteration limit $T$.
\ENSURE Best verified feasible design, or an unsuccessful search status.
\STATE Initialize the optimizer and $\mathcal{D}_0=\emptyset$, with no feasible incumbent.
\FOR{$t=0,\ldots,T-1$}
\STATE Generate and repair candidate batch $\mathcal{B}_t$.
\STATE Obtain global predictions from $\Phi_f$ and $\Phi_s$.
\STATE Refit eligible local models if $\mathcal{D}_t$ has changed. Otherwise, retain the available models or global fallbacks.
\STATE Compute $p_t$, $m_t$, and screening threshold $\tau_t$.
\STATE Retain $\mathcal{P}_t=\{x\in\mathcal{B}_t:p_t(x)\geq\tau_t\}$.
\STATE Select $\mathcal{A}_t\subseteq\mathcal{P}_t$ using the current quota and priority score $\psi_t$.
\STATE Evaluate $\mathcal{A}_t$, reusing cached results when available.
\STATE Update the best verified feasible design and append verified records to obtain $\mathcal{D}_{t+1}$.
\STATE Return evaluated fitness values and rejection values for unselected candidates to the optimizer.
\STATE Update the optimizer according to its search rule.
\ENDFOR
\STATE Verify the provisional returned candidate if it has not been evaluated.
\RETURN Best verified feasible design, or unsuccessful search status if none is available.
\end{algorithmic}
\end{algorithm}



\subsection{Feasibility Screening and Cost-Based Selection}
\label{subsec:candidate_screening_ranking}

Candidate selection proceeds through conservative feasibility screening followed by cost-oriented quota allocation. For readability, predictions are written below as functions of $x$, leaving the fixed layout representation implicit.

First, candidates with $p_t(x) < \tau_t$ are filtered out to avoid wasting FEA calls on designs likely to violate code checks. Before local feasibility calibration is activated, $\tau_t$ equals the validation-selected global threshold. Once calibrated probabilities become available, $\tau_t$ is dynamically adapted using the locally verified feasible designs in $\mathcal{D}_t$ according to
\begin{equation}
\tau_t=\alpha Q_{1-\kappa}\!\left(\{p_t(x_i):y_f(x_i)=1\}\right),
\label{eq:calibrated_threshold}
\end{equation}
where $Q_{1-\kappa}$ denotes the empirical $(1-\kappa)$-quantile targeting a nominal feasible recall $\kappa$, and $0<\alpha\leq 1$ applies a conservative margin to prevent false rejection of valid designs. The retained candidate set is $\mathcal{P}_t=\{x\in\mathcal{B}_t:p_t(x)\geq\tau_t\}$.

Second, retained candidates in $\mathcal{P}_t$ are prioritized using a score that combines estimated material cost with a penalty for low predicted passing likelihood. The score is defined as
\begin{equation}
\begin{aligned}
\widehat C_t(x)&=\pi_s m_t(x)+\pi_c(x)\widetilde m_c(x),\\
\psi_t(x)&=\widehat C_t(x)+\eta\max\{0,p_{\mathrm{ref}}-p_t(x)\},
\end{aligned}
\label{eq:calibrated_priority_score}
\end{equation}
where $\widetilde m_c(x)$ is the geometric concrete mass, $p_{\mathrm{ref}}$ is a reference probability threshold, and $\eta$ converts probability deficits into cost units. A smaller priority score $\psi_t(x)$ indicates higher evaluation priority, discouraging the selection of superficially cheap designs that lie near the infeasibility boundary.

Under a limited evaluation budget, the number of candidates selected from $\mathcal{P}_t$ for FEA is governed by the evaluation quota
\begin{equation}
n_t=\min\{|\mathcal{P}_t|,\;\max\{n_{\min},\operatorname{round}(\theta_t|\mathcal{P}_t|)\}\},
\label{eq:evaluation_quota}
\end{equation}
where $n_{\min}$ is the minimum batch quota (capped by $|\mathcal{P}_t|$) and $\theta_t$ is the evaluation ratio. Before the first verified feasible design is found, a larger $\theta_t$ is used and all $n_t$ slots are filled by lowest-$\psi_t$ candidates to accelerate feasible-region discovery. Once a feasible solution is obtained, $\theta_t$ is reduced and the quota is divided among three disjoint subsets: (1) Top-ranked candidates by $\psi_t$ support cost exploitation; (2) Candidates with the smallest feasibility-score deficit (ties broken by $\psi_t$) support boundary refinement; (3) Random candidates from $\mathcal{P}_t$ maintain search diversity. Specific ratios and hyperparameter values are provided in Section~\ref{subsec:optimization_benchmark_settings}.

\subsection{Optimizer Feedback and Local Updates}
\label{subsec:online_update_framework}

Evaluated candidates in $\mathcal{A}_t$ are ranked for the optimizer using a feasibility-first rule. Verified feasible designs are always preferred and ordered by their true material cost $C(x)$, whereas evaluated infeasible designs are ordered by a composite penalty combining normalized constraint violations, failed-check indicators, and material cost (\ref{app:implementation_details}). Unselected candidates ($\mathcal{B}_t \setminus \mathcal{A}_t$) receive a large constant rejection value $M_{\mathrm{rej}}$ so that optimizers do not favor unverified designs over confirmed feasible solutions. This placeholder value is excluded from local calibration and final reporting.

Once $\mathcal{A}_t$ is evaluated, all new verified outcomes are added to $\mathcal{D}_t$—binary feasibility labels (including analysis failures) update Platt scaling, while valid member-design records update the reinforcement residual model—with the global networks remaining frozen. Throughout the search, CASIO tracks the best FEA-verified feasible design as the incumbent solution. If the optimizer's final returned candidate has not yet been evaluated, it undergoes a final structural verification (counted toward total FEA calls). Thus, while surrogates guide search allocation, the final feasibility decision remains strictly with the true structural evaluator.
