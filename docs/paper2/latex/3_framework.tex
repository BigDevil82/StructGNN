


\section{Calibrated Surrogate-Assisted Optimization Framework}
\label{sec:optimization_framework}

This section describes how the surrogate predictions defined in Section~\ref{sec:problem_surrogate} are used to allocate FEA evaluations during optimization.

\subsection{Overall Framework}
\label{subsec:overall_framework}

The overall framework is illustrated in Fig.~\ref{fig:calibrated_optimization_framework}. For a fixed shear wall layout $L$ and design condition $c$, the optimization task is to search the design space $\mathcal{X}$ for section and material parameters that minimize the material cost while satisfying all structural checks. At iteration $t$, the optimizer $\mathcal{O}$ generates a batch of candidate designs:
\begin{equation}
\mathcal{B}_t=
\left\{
x_{t,1},x_{t,2},\ldots,x_{t,N_b}
\right\}
\label{eq:candidate_batch}
\end{equation}
where $N_b$ is the batch size.

For each candidate $x_{t,i}$, the surrogate input follows the representation defined in Section~\ref{subsec:layout_parameter_model}:
\begin{equation}
z_{t,i}=\left(G,d_{t,i},q\right)
\label{eq:candidate_input_framework}
\end{equation}
where the layout-related terms $G$ and $q$ remain fixed in a single optimization task, while the design vector $d_{t,i}$ varies among candidates. The global surrogate models and the online calibration module then provide the calibrated feasibility probability $\hat{p}_{f,t,i}^{C}$ and calibrated reinforcement estimate $\hat{m}_{s,t,i}^{C}$ according to Section~\ref{subsec:online_local_calibration}.

These calibrated predictions are used only to decide which candidates should receive true evaluation. The selected subset is denoted by $\mathcal{S}_t\subseteq \mathcal{B}_t$. For each candidate in $\mathcal{S}_t$, the true evaluator produces FEA-verified results:
\begin{equation}
\mathcal{E}(L,c,x_{t,i})
\rightarrow
(y_{f,t,i},m_{s,t,i},m_{c,t,i},r_{t,i}),
\quad x_{t,i}\in\mathcal{S}_t
\label{eq:true_eval_framework}
\end{equation}
These verified results are used to update the optimizer and to expand the local calibration set. Candidates not selected for FEA receive a rejected-objective value so that the optimizer can still be updated with a complete batch.

\subsection{Candidate Screening and Priority Ranking}
\label{subsec:candidate_screening_ranking}

The surrogate-based pre-evaluation module consists of two consecutive operations: feasibility screening and priority ranking. The first operation removes candidates with very low calibrated feasibility probability. The second operation selects a subset of the remaining candidates for FEA according to calibrated material cost, feasibility risk, and random exploration.

Given the calibrated feasibility probability $\hat{p}_{f,t,i}^{C}$ and the screening threshold $\tau_t$, the candidates passing the feasibility screening are defined as
\begin{equation}
\mathcal{B}_{t}^{pass}
=
\left\{
x_{t,i}\in\mathcal{B}_t
\mid
\hat{p}_{f,t,i}^{C}\ge \tau_t
\right\}
\label{eq:pass_set}
\end{equation}
The threshold $\tau_t$ follows the conservative strategy introduced in Section~\ref{subsec:online_local_calibration}. Its purpose is to avoid removing potentially feasible designs.


For each candidate that passes the feasibility screening, a priority score is computed as
\begin{equation}
S_{t,i}^{C}
=
\hat{C}_{t,i}^{C}
+
\eta
\max
\left(
0,
p_0-\hat{p}_{f,t,i}^{C}
\right)
\label{eq:calibrated_priority_score}
\end{equation}
where $\hat{C}_{t,i}^{C}$ is the calibrated surrogate cost defined in Eqn.~\ref{eq:calibrated_cost}, $p_0$ is the reference feasibility probability, and $\eta$ is the feasibility-risk penalty coefficient. The coefficient $\eta$ converts the probability deficit below $p_0$ into an equivalent cost penalty, so a larger value makes the ranking more conservative with respect to feasibility. Thus, lower scores indicate candidates that are both economical and less risky.

The method does not impose a fixed total number of FEA calls. Instead, it adaptively determines how many candidates in each iteration are submitted to FEA.

Before any feasible design has been observed, a larger per-iteration evaluation quota is used to maintain exploration:
\begin{equation}
K_t^{pre}
=
\min
\left(
|\mathcal{B}_t^{pass}|,
\max
\left(
K_{\min},
\left\lceil r_{pre}|\mathcal{B}_t^{pass}|\right\rceil
\right)
\right)
\end{equation}
where $K_{\min}$ is the minimum number of evaluated candidates. 
The candidates with the lowest calibrated cost scores are then selected for FEA.

After at least one feasible design has been found, the evaluation quota is reduced:
\begin{equation}
K_t
=
\min
\left(
|\mathcal{B}_t^{pass}|,
\max
\left(
K_{\min},
\left\lceil r|\mathcal{B}_t^{pass}|\right\rceil
\right)
\right)
\end{equation}
The selected candidates are composed of three parts: low-cost candidates, low-risk candidates, and randomly sampled candidates. 
In the experiments, these three parts account for 60\%, 25\%, and 15\% of the per-iteration evaluation quota, respectively. 
This design preserves exploitation toward low-cost feasible regions while retaining a small amount of exploration.


Through this two-stage mechanism, the feasibility surrogate and the reinforcement surrogate have different but complementary functions. The feasibility surrogate reduces the probability that clearly infeasible candidates consume FEA calls, whereas the reinforcement surrogate ranks the remaining candidates by material economy. The output of this module is the selected subset $\mathcal{S}_t$, which is submitted to FEA in the current iteration.


\subsection{Optimizer and Surrogate Update after Candidate Evaluation}
\label{subsec:online_update_framework}

After candidate screening and priority ranking, only the selected candidates $\mathcal{S}_t$ are evaluated by the true evaluator. The optimizer is updated using two types of objective values: verified fitness values for candidates in $\mathcal{S}_t$ and rejected-objective values for the others. Because the optimizers minimize a scalar objective value, smaller values indicate better candidates.

For a truly evaluated candidate design ${x}_{t,i}$, the scalar fitness used by the optimizer is defined as
\begin{equation}
F({x}_{t,i})
=
\begin{cases}
C({x}_{t,i}), 
& {x}_{t,i}\in\Omega_f,\\[3pt]
P_0+\lambda_v V({x}_{t,i})+\lambda_c C({x}_{t,i}),
& {x}_{t,i}\notin\Omega_f
\end{cases}
\label{eq:true_fitness}
\end{equation}
where $C({x}_{t,i})$ is the material cost computed from the verified reinforcement and concrete quantities, $\Omega_f$ denotes the feasible domain, $P_0$ is a base infeasibility penalty, and $\lambda_v$ and $\lambda_c$ are the violation and cost weights for infeasible candidates. The violation measure is
\begin{equation}
\begin{aligned}
V({x}_{t,i})
={}&
\sum_{r}
\max\left(
0,
\frac{g_r({x}_{t,i})-g_r^{\lim}}{g_r^{\lim}}
\right) \\
&+
\sum_{s}
\max\left(
0,
\frac{h_s^{\lim}-h_s({x}_{t,i})}{h_s^{\lim}}
\right) \\
&+
\sum_{q} b_q({x}_{t,i})
\end{aligned}
\label{eq:violation_score}
\end{equation}
where $g_r$ denotes upper-bound constraints, $h_s$ denotes lower-bound constraints, and $b_q\in\{0,1\}$ indicates whether a discrete code-check item fails. Thus, feasible candidates are ranked by material cost, while infeasible evaluated candidates are assigned a penalty according to their code-violation level.

Candidates not submitted to FEA do not have verified feasibility or cost values. To keep the optimizer update well defined, these candidates are assigned a large rejected objective:
\begin{equation}
F^{rej}(x_{t,i}) = M_{rej},
\quad M_{rej}=1.0\times 10^{12}
\label{eq:rejected_objective}
\end{equation}
This value is much larger than normal material-cost or penalty values, so these candidates are dominated in the minimization process and are effectively skipped.

For surrogate update, the FEA-verified samples are added to the local calibration set:
\begin{equation}
\begin{aligned}
\mathcal{D}_{t+1}^{loc}
=
\mathcal{D}_{t}^{loc}
\cup
\bigl\{
&(z_{t,i},
\hat{p}_{f,t,i}^{G},
\hat{m}_{s,t,i}^{G},
y_{f,t,i},
m_{s,t,i})
&\mid x_{t,i}\in\mathcal{S}_t
\bigr\}
\end{aligned}
\label{eq:local_set_update}
\end{equation}
The stored global predictions and verified labels allow the calibration module to learn layout-specific probability shifts and reinforcement residuals.

At the beginning of optimization, $\mathcal{D}_{t}^{loc}$ may be empty or too small for reliable calibration, and the framework mainly relies on global surrogate predictions with conservative screening. As more FEA-verified samples are accumulated, the local calibration module becomes active and progressively corrects the global surrogate bias. This online update process allows the surrogate module to become more consistent with the current optimization task without retraining the full global graph model.

\subsection{Algorithm Summary}
\label{subsec:algorithm_summary}

The complete calibrated surrogate-assisted optimization procedure is summarized in Algorithm~\ref{alg:csa_optimization}. The algorithm takes a fixed layout, design condition, design space, optimizer, global surrogate models, true evaluator, rejected objective, and per-iteration evaluation quota settings as inputs. It outputs the best feasible design verified during the search.

\begin{algorithm}[t]
\caption{Calibrated surrogate-assisted optimization}
\label{alg:csa_optimization}
\begin{algorithmic}[1]
\REQUIRE Layout $L$, design condition $c$, design space $\mathcal{X}$, optimizer $\mathcal{O}$, global surrogates ${SM}_f$ and ${SM}_s$, true evaluator $\mathcal{E}$, screening threshold $\tau_t$, rejected objective $M_{rej}$, initial local calibration set $\mathcal{D}_{0}^{loc}=\emptyset$.
\ENSURE Best feasible design verified by $\mathcal{E}$.
\FOR{$t=0,1,\ldots,T-1$}
\STATE Generate a candidate batch $\mathcal{B}_t$ using optimizer $\mathcal{O}$.
\STATE Construct candidate representations $z_{t,i}=\left(G,d_{t,i},q\right)$ for all $x_{t,i}\in\mathcal{B}_t$.
\STATE Obtain global predictions $\hat{p}_{f,t,i}^{G}=SM_f(z_{t,i})$ and $\hat{m}_{s,t,i}^{G}=SM_s(z_{t,i})$.
\IF{$\mathcal{D}_{t}^{loc}$ contains enough verified samples for calibration}
\STATE Compute calibrated predictions $\hat{p}_{f,t,i}^{C}$ and $\hat{m}_{s,t,i}^{C}$.
\ELSE
\STATE Set $\hat{p}_{f,t,i}^{C}=\hat{p}_{f,t,i}^{G}$ and $\hat{m}_{s,t,i}^{C}=\hat{m}_{s,t,i}^{G}$.
\ENDIF
\STATE Screen candidates according to $\hat{p}_{f,t,i}^{C}$ and $\tau_t$.
\STATE Rank the retained candidates using the score $S_{t,i}^{C}$.
\STATE Select $\mathcal{S}_t$ for true FEA and code-based checking.
\STATE Evaluate each $x_{t,i}\in\mathcal{S}_t$ using $\mathcal{E}$ to obtain $(y_{f,t,i},m_{s,t,i},m_{c,t,i},r_{t,i})$.
\STATE Compute the verified fitness $F(x_{t,i})$ for each $x_{t,i}\in\mathcal{S}_t$.
\STATE Assign $M_{rej}$ to candidates not in $\mathcal{S}_t$.
\STATE Update optimizer $\mathcal{O}$ using verified fitness values and rejected-objective values.
\STATE Update the local calibration set $\mathcal{D}_{t+1}^{loc}$.
\ENDFOR
\STATE \RETURN The best feasible design verified by $\mathcal{E}$.
\end{algorithmic}
\end{algorithm}

The proposed algorithm keeps the true structural evaluator as the only source of verified feasibility and objective values. The surrogate module only changes how candidate designs are prioritized before evaluation.
