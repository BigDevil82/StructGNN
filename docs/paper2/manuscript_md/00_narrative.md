# 整篇文章的叙事逻辑

本文要讲的核心问题是：剪力墙结构设计优化中，真正昂贵的环节不是优化算法本身，而是每一个候选方案都需要经过 OpenSees 有限元分析和规范校核。若直接在优化过程中大量调用 FEA，计算成本会迅速放大，使得面向多布局、多设计条件的截面与材料优化难以高效开展。因此，本文的目标不是用机器学习模型替代结构分析，而是构建一种更高效地分配 FEA 预算的优化框架：尽量少分析明显无效或低价值的候选方案，把有限的真实 FEA 调用集中到更可能可行且更有优化潜力的方案上。

为此，本文首先建立一个参数化剪力墙结构建模、分析与设计校核流程。给定剪力墙布局、截面材料参数和抗震设防条件，该流程能够自动生成结构模型，执行 OpenSees 分析，并通过设计校核得到结构是否可行以及材料用量等结果。基于 143 套剪力墙布局和随机采样的设计参数，本文构建了用于训练代理模型的数据集。这个数据集的作用不是直接给出最终优化答案，而是让模型学习不同布局和设计条件下，结构可行性与钢筋用量的大致规律。

在此基础上，本文训练两个全局代理模型：一个预测候选方案是否可能通过校核，另一个预测钢筋用量。两个模型共享统一的布局-参数融合表征，用于同时接收剪力墙布局图、全局布局特征、截面材料参数和设计条件。实验表明，全局代理模型在测试集上已经具备较好的整体预测能力：可行性模型能够识别大量明显不可行方案，钢筋模型能够较准确地反映候选方案之间的用量差异。但同时，全局模型并不完美。它在部分布局上存在概率偏差，在高钢筋用量区间也会出现系统性低估。这说明代理模型不能被直接当作最终评价器使用。

本文的关键思路是引入在线局部校准。由于优化过程是围绕单个布局和当前设计条件展开的，优化过程中已经产生的真实 FEA 结果本身就是高价值的局部数据。本文将这些 FEA 样本复用起来，对全局代理模型进行轻量校准：一方面修正可行性概率，使筛选阈值更适合当前布局；另一方面学习钢筋预测残差，使材料用量排序和造价预估更贴近当前搜索区域。这样，代理模型不是静态地一次训练后直接使用，而是在优化过程中逐步适配当前问题。

最终，本文将全局代理模型与在线局部校准机制嵌入结构优化算法中。优化算法生成一批候选方案后，先由可行性代理模型保守筛掉明显不可行方案，再由钢筋用量代理模型和快速混凝土用量估计得到候选造价分数，只选择更有潜力的候选进入真实 FEA。真实 FEA 结果一方面用于更新优化算法，另一方面继续补充局部校准数据。通过这种方式，最终最优方案仍然由真实 FEA 和规范校核确认，但中间大量低价值候选可以被跳过，从而显著减少 FEA 调用次数。

因此，本文的主线不是提出一个单纯追求最高预测精度的代理模型，而是提出一个面向结构优化流程的代理辅助机制。它的贡献在于把参数化结构分析、全局代理模型、在线局部校准和优化算法有机结合起来，使剪力墙设计优化能够在保持可行率和材料造价质量基本不变的前提下，大幅降低有限元分析开销。这一叙事需要贯穿全文：代理模型服务于 FEA 预算分配，而不是替代最终结构验算；局部校准服务于当前布局适配，而不是离线模型竞赛；优化结果服务于证明工程计算效率提升，而不是单纯展示机器学习指标。
