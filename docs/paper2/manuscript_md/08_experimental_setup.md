# 3. Experimental Setup

本节说明实验数据、模型训练、优化基准和评价指标。所有结果分析均放在第 4 节，本节只描述实验如何构造，以保证后续比较具有可复现性和公平性。

## 3.1 Dataset and Structural Evaluation Settings

代理模型数据集由剪力墙布局和参数化结构评价流程生成。布局数据来自预处理后的 CAD/JSON 平面文件，每个布局包含剪力墙、梁和节点连接等几何信息。本文使用的代理数据集共包含 143 个布局和 714,972 个候选设计样本。数据按布局分组划分为训练集、验证集和测试集，避免同一布局的样本同时出现在训练和测试阶段。当前划分包含 100 个训练布局、21 个验证布局和 22 个测试布局，对应样本数分别为 499,977、104,999 和 109,996。

每个样本由一个布局、一个设计条件组合和一个截面材料方案构成。采样参数包括楼层数、墙厚、主梁和次梁截面尺寸、混凝土强度等级、抗震设防烈度、场地类别和地震分组等。墙厚和梁截面尺寸从离散工程候选值中采样，混凝土强度等级从 C30 到 C50 的候选等级中选择。设计条件覆盖不同楼层数、设防烈度、场地类别和地震分组，用于增强代理模型对不同结构需求水平的泛化能力。

每个候选方案通过参数化结构评价流程获得监督标签。结构分析基于 OpenSees 完成，剪力墙采用 MVLEM 类单元建模。分析工况包括用于结构响应评估和构件设计校核的主要竖向荷载与地震作用。评价流程输出层间位移、扭转响应、周期特征、剪重比、刚度比、墙梁构件内力需求和截面设计结果，并据此形成综合可行性标签 `final_pass`。同时，设计校核流程给出钢筋用量 `material_steel_kg` 和混凝土用量等材料指标。

测试集中的 22 个布局来自三个布局族，其中 L17 包含 7 个测试布局，L27 包含 4 个测试布局，L1L28 包含 11 个测试布局。代理模型性能评估使用完整测试集。优化实验使用从测试集中选出的主测试布局，每个布局族选择 5 个布局，共 15 个布局，以保证不同方法在未见布局上的比较具有一致条件。主优化实验中，布局族与设防烈度的对应关系为 L17: 7.0、L27: 7.5、L1L28: 8.0；场地类别和地震分组按 layout-seed 组合随机生成，并在所有对比方法之间保持一致。

## 3.2 Surrogate Model Training Settings

全局代理模型包括可行性代理模型和钢筋用量代理模型。二者均采用第 2.3 节定义的 LayoutParamGNN 架构，以 room graph、全局布局统计特征和设计参数作为输入。图卷积采用 GraphSAGE 作为默认消息传递算子，图编码层数为 3。可行性模型使用较大的隐藏维度以提高分类能力，钢筋模型使用较大的 batch size 以稳定连续目标训练。

可行性代理模型以 `final_pass` 为分类目标，使用带类别权重的 binary cross entropy loss 训练。模型选择不以默认分类阈值下的最高 F1 为唯一目标，而是根据验证集上的保守筛选性能选择筛选阈值。具体地，在满足目标 feasible recall 的约束下，选择 reject rate 较高的模型和阈值。本文主实验采用目标 feasible recall 为 0.995 的保守筛选模型。

钢筋用量代理模型以 `material_steel_kg` 为回归目标。训练时对钢筋用量进行 `log1p` 变换和标准化，并使用 Smooth L1 loss 优化。推理时将模型输出反变换回 kg 空间。钢筋代理模型用于候选造价排序和 FEA 预算分配，因此除 MAE、RMSE、MAPE 和 $R^2$ 等回归指标外，还评估排序相关指标。

为验证输入表征和模型选择的作用，代理模型实验包含若干 baseline 或消融设置。可行性任务比较表格型机器学习模型、参数与布局统计特征模型以及 LayoutParamGNN。钢筋任务比较参数-only MLP、参数加全局布局统计特征 MLP、LightGBM 回归模型和 room-graph LayoutParamGNN。局部校准实验单独比较不同校准器：可行性概率校准包括 Platt scaling、isotonic regression、local logistic calibration、残差概率修正和 ensemble vote correction；钢筋残差校准包括 Ridge regression、Gaussian process regression、LightGBM、KNN 和小型 MLP 等回归模型。最终在线优化实验采用验证表现和稳定性较好的校准配置。

## 3.3 Optimization Benchmark Settings

优化实验用于评估代理辅助筛选是否能够在保持解质量的同时减少真实 FEA 调用。本文比较三类方法。第一类为 `full` baseline，即优化算法生成的候选方案全部进入真实有限元分析和规范校核。第二类为 `gnn_cost`，使用钢筋代理模型和快速混凝土估计进行候选造价预排序，但不进行可行性筛选。第三类为 `gnn_screen_cost`，即本文主方法，同时使用可行性筛选、钢筋造价预排序和在线局部校准。

主优化实验以遗传算法为主要优化器。当前主要设置为 population size 48、generation number 15、elite size 2、mutation rate 0.3。每个测试布局使用 5 个随机种子重复运行。对于每个 layout-seed 组合，所有方法共享相同的布局、设防烈度、场地类别、地震分组和优化搜索空间。实现中对重复候选设计进行缓存，因此真实 FEA 调用次数可能低于名义候选数量。

为了验证方法不依赖单一优化算法，附加实验还考虑 PSO 和 random search。PSO 用于测试代理筛选在另一类群体智能优化器中的适用性；random search 用于检验即使没有复杂搜索策略，仅通过代理筛选和预算分配是否也能减少无效 FEA 调用。对于不同优化算法，`full` 与代理辅助方法均使用相同的候选生成预算和随机种子设置。

代理辅助优化中的关键预算参数包括候选保留比例、最小真实评价数量和可行性风险惩罚。主实验中，cost preselection 每批至少评价 8 个候选，并按候选数量的一定比例选择进入真实 FEA。可行性概率用于筛掉明显不可行方案，并在造价评分中引入风险惩罚。在线局部校准启用后，优化过程中新产生的真实 FEA 结果会被加入局部校准样本集，用于后续批次的可行性概率和钢筋残差校准。

所有方法的最终最优方案必须经过真实有限元分析和规范校核确认。代理模型只决定候选方案是否进入真实评价队列，不直接接受代理预测结果作为最终结构设计结果。

## 3.4 Evaluation Metrics

代理模型评价分为分类、回归和排序三类。可行性模型报告 ROC-AUC、PR-AUC、precision、recall 和 F1 等分类指标，同时报告面向筛选任务的 reject rate、feasible recall、false reject count 和 screen recall。这里 reject rate 表示被代理模型提前筛掉的候选比例，feasible recall 或 screen recall 表示真实可行样本中被保留下来的比例。

钢筋用量模型报告 MAE、RMSE、MAPE、$R^2$ 和 bias 等回归指标。由于钢筋代理模型主要用于候选排序，还报告 pairwise ranking accuracy、large-gap ranking accuracy、Spearman correlation 和 top-fraction recall 等排序指标。误差分析进一步按真实钢筋用量分位区间、图规模、设计参数类别和布局 ID 进行分组，以识别全局代理模型的系统性偏差。

局部校准评价关注校准前后代理模型在单布局 holdout 样本上的变化。可行性校准使用 Brier score、expected calibration error、PR-AUC、F1、screen reject rate 和 screen recall 等指标。钢筋残差校准使用 MAE、RMSE、bias、$R^2$ 和排序指标。为评估样本效率，校准实验在不同局部样本数量下重复进行，并统计跨布局平均表现。

优化实验的核心指标包括真实 FEA 调用次数、FEA reduction、可行解成功率、首次发现可行解所需 FEA 次数、最终可行方案材料造价以及相对于 full baseline 的造价差异。对于同一 layout-seed 组合，代理辅助方法与 full baseline 进行成对比较。若 full baseline 与代理辅助方法均找到可行解，则比较最终材料造价比；若某些布局在 full baseline 下也未找到可行解，则将其作为布局或搜索空间难度分析的一部分，而不单独归因于代理方法失效。
