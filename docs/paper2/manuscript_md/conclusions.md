# 5. Conclusions

本文围绕剪力墙结构截面与材料优化中的高计算成本问题，提出了一种校准代理辅助的结构优化框架。该框架首先基于工程剪力墙布局、参数化 OpenSees 分析和规范设计校核流程构建代理模型数据集；随后训练可行性代理模型和钢筋用量代理模型，分别用于识别明显不可行候选和估计候选方案的材料造价排序；进一步利用优化过程中已经产生的真实 FEA 结果建立在线局部校准模型，以修正全局代理模型在当前布局和局部搜索区域中的偏差。

全局代理模型实验表明，布局信息对剪力墙截面优化代理建模具有显著作用。对于可行性判断任务，仅使用设计参数的 MLP 在测试集上的 PR-AUC 和 F1 分别为 0.6137 和 0.5927；加入全局布局统计特征后，二者提升至 0.8163 和 0.7370；进一步采用 room-graph LayoutParamGNN 后，ROC-AUC、PR-AUC 和 F1 分别达到 0.9693、0.8593 和 0.7688。在保守筛选设置下，LayoutParamGNN 能够提前拒绝 47.36% 的候选样本，同时保持 0.9998 的可行样本召回率，仅误拒 3 个真实可行样本。对于钢筋用量预测任务，LayoutParamGNN 将 MAE 降至 11.48 t，$R^2$ 提升至 0.924，并取得 0.9787 的 pairwise ranking accuracy 和 0.9483 的 top-10% recall，说明其能够为候选方案造价排序提供有效依据。

在线局部校准实验进一步验证了利用优化过程中少量 FEA 样本修正全局代理模型的可行性。采用 100 个当前布局样本进行校准后，可行性模型的 Brier score 从 0.0749 降至 0.0437，ECE 从 0.0895 降至 0.0333，筛选拒绝率由 0.4708 提高到 0.5481，同时 screen recall 仍保持在 0.9939。钢筋用量模型的局部残差校准效果更为明显，MAE 从 11.48 t 降至 2.04 t，RMSE 从 12.30 t 降至 2.76 t，$R^2$ 从 0.847 提升至 0.994，MAPE 从 9.26% 降至 1.64%。这些结果说明，全局代理模型在跨布局预测中不可避免存在偏差，但优化过程中自然产生的少量真实分析结果可以显著提高其对当前布局的适应性。

在 15 个测试布局和 5 个随机种子的优化实验中，校准代理辅助策略在 GA、PSO 和 random search 三类优化算法下均显著减少了真实 FEA 调用次数。与 full FEA baseline 相比，仅使用造价代理预排序时平均 FEA 调用减少约 53.8%；进一步结合可行性筛选与造价预排序后，平均 FEA 调用减少约 64.6%。其中，GA、PSO 和 random search 下的 FEA 调用降幅分别约为 65.9%、62.4% 和 65.6%。在解质量方面，`Screen + cost` 策略的平均可行解发现率为 63.6%，接近 full FEA baseline 的 65.8%；在 full baseline 和代理辅助方法均找到可行解的案例中，最终材料造价平均仅增加约 1.19%。这表明，所提出方法能够以较小的解质量代价换取显著的 FEA 预算节省。

本文工作的工程意义在于，将代理模型从直接替代结构分析结果的角色转变为辅助分配有限元计算预算的角色。可行性代理模型用于减少明显不可行候选对 FEA 预算的占用，钢筋用量代理模型用于将真实分析集中到更有经济潜力的候选方案上，局部校准则使这两个判断逐步适应当前优化问题。由于最终方案仍由真实有限元分析和规范校核确认，该使用方式更符合结构设计对可靠性的要求。对于需要反复评估大量候选方案的剪力墙结构优化任务，所提出框架可以在基本保持可行率和材料造价水平的前提下降低计算开销，从而提高智能优化方法在工程设计流程中的可用性。

本文仍存在若干局限。首先，实验布局虽然来源于工程方案，但当前优化变量主要集中在截面尺寸和材料等级，尚未考虑墙体位置调整、边缘构件细化和更完整的施工构造约束。其次，代理模型和局部校准方法依赖已有参数空间中的样本分布，当优化任务超出训练数据覆盖范围时，仍可能出现预测偏差。再次，部分布局在当前搜索空间下即使采用 full FEA 搜索也难以找到可行方案，后续需要结合布局优化、搜索空间扩展和更真实的工程项目验证进一步分析。未来研究可从三个方向展开：引入更丰富的工程设计变量，构建面向实际项目的连续优化与多目标优化框架，以及发展带不确定性估计的代理筛选策略，以进一步提升代理辅助结构优化的可靠性和适用范围。
