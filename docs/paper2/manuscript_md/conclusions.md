# 5. Conclusions

本文围绕剪力墙结构截面与材料优化中的高计算成本问题，提出了一种校准代理辅助的结构优化框架。首先基于工程剪力墙布局、参数化 OpenSees 分析和规范设计校核流程构建代理模型数据集；随后训练可行性代理模型和钢筋用量代理模型，分别用于识别明显不可行候选和估计候选方案的材料造价排序；进一步利用优化过程中已经产生的真实 FEA 结果建立在线局部校准模型，以修正全局代理模型在当前布局和局部搜索区域中的偏差。

实验结果表明，全局代理模型能够为剪力墙结构优化提供有效的初始预测能力。可行性代理模型在保守筛选设置下能够提前排除大量明显不可行候选，并保持较高的可行样本保留率；钢筋用量代理模型虽然不适合作为最终材料用量的直接替代，但能够提供较有价值的候选排序信息。局部校准实验进一步说明，少量当前布局上的 FEA 样本可以改善全局代理模型的概率校准和钢筋残差预测，从而提高其在单个优化任务中的适应性。

在优化实验中，校准代理辅助策略能够在保持最终可行率和材料造价基本接近 full FEA baseline 的同时，显著减少真实 FEA 调用次数。过程分析表明，效率提升主要来自两个互补机制：可行性筛选减少明显违反结构约束的候选方案，造价预排序减少过分保守或经济性较差的候选方案。代表性优化轨迹和布局级成功率分析也显示，代理辅助方法在多数可解布局上能够保持接近 full FEA 的优化能力，而部分困难布局即使采用完整 FEA 搜索也难以找到可行解，说明其失败更可能与布局本身或当前截面材料搜索空间有关。

本文工作的工程意义在于，将代理模型从“替代分析结果”的角色转变为“辅助分配有限元计算预算”的角色。这种使用方式更符合结构设计对可靠性的要求，因为最终方案仍由真实有限元分析和规范校核确认。对于需要反复评估大量候选方案的剪力墙结构优化任务，所提出的框架可以在不明显牺牲设计质量的前提下降低计算开销，从而提高智能优化方法在工程设计流程中的可用性。

本文仍存在若干局限。首先，实验布局虽然来源于工程方案，但当前优化变量主要集中在截面尺寸和材料等级，尚未考虑墙体位置调整、边缘构件细化和更完整的施工构造约束。其次，代理模型和局部校准方法依赖已有参数空间中的样本分布，当优化任务超出训练数据覆盖范围时，仍可能出现预测偏差。再次，部分布局在当前搜索空间下难以找到可行方案，后续需要结合布局优化、搜索空间扩展和更真实的工程项目验证进一步分析。未来研究可从三个方向展开：引入更丰富的工程设计变量，构建面向实际项目的连续优化与多目标优化框架，以及发展带不确定性估计的代理筛选策略，以进一步提升代理辅助结构优化的可靠性和适用范围。
