# 1. Introduction

剪力墙结构是高层建筑和抗震结构设计中常用的主要抗侧力体系，其结构性能与墙体布置、截面尺寸、材料强度以及抗震设防条件密切相关。在实际设计中，工程师通常需要在满足承载力、变形和构造要求的前提下，尽量降低混凝土和钢筋等材料用量。随着建筑平面形式、设计条件和性能约束的复杂化，剪力墙结构的优化设计逐渐从经验驱动转向计算驱动。通过优化算法自动搜索截面和材料方案，有望提高设计效率，并为不同布局方案提供更系统的性能与经济性比较。

然而，剪力墙结构优化面临一个直接困难：每一个候选方案都需要经过结构分析和设计校核才能判断其是否可行，并得到材料用量和造价。对于基于有限元分析的流程而言，候选方案数量一旦增大，计算开销会迅速累积。遗传算法、粒子群优化、贝叶斯优化等智能优化方法虽然能够在复杂搜索空间中寻找较优设计，但如果每一代或每一批候选都调用完整有限元分析，则整体效率仍然受限。因此，如何在保证最终设计可靠性的同时减少无效有限元分析调用，是剪力墙结构优化设计中的关键问题。

已有研究通常从两个方向缓解这一问题。一类方法改进优化算法本身，例如通过启发式搜索策略、约束处理机制或多目标优化框架提高搜索效率 `[文献]`。这类方法能够减少盲目搜索，但仍然需要大量真实结构分析来评价候选方案。另一类方法引入代理模型，用机器学习模型近似有限元分析或设计校核结果，从而降低单次候选评价成本 `[文献]`。近年来，随着深度学习和图神经网络的发展，代理模型还可以进一步利用结构拓扑、构件连接关系或建筑平面布局信息，对结构响应、可行性或材料用量进行预测 `[文献]`。

尽管代理模型为结构优化提供了重要可能性，但在工程设计问题中，代理模型很难被完全视为有限元分析的替代品。首先，代理模型的精度依赖训练数据覆盖范围，当优化过程进入训练数据较少覆盖的参数区域时，预测误差可能增大。其次，剪力墙结构的性能不仅受截面参数影响，也受布局拓扑和设计条件影响，跨布局泛化本身具有难度。再次，对于接近规范限值的边界样本，结构是否可行可能对局部参数变化非常敏感，二分类代理模型很难保证绝对可靠。对于材料用量预测，钢筋用量又依赖多工况分析后的内力需求和截面设计结果，误差可能在高用量区间表现为系统性偏差。

因此，本文关注的核心问题不是如何训练一个能够完全替代有限元分析的代理模型，而是在代理模型不可避免存在误差的情况下，如何仍然充分发挥其在优化过程中的价值。换言之，代理模型不应被简单理解为最终分析结果的替代品，而应被视为一种有限元预算分配工具：它可以帮助识别明显不可行的候选方案，估计候选方案的相对优劣，并将真实有限元分析优先分配给更有希望的设计。这样，即使代理模型不能保证每一个预测都完全准确，仍然能够在优化流程层面提高整体效率。

基于这一思想，本文提出一种校准代理辅助的剪力墙结构设计优化框架。首先，基于参数化建模、OpenSees 有限元分析和规范设计校核流程，构建包含多种剪力墙布局、截面材料参数和设计条件的数据集。然后，训练两个全局代理模型：一个用于预测候选方案的综合可行性，另一个用于预测钢筋用量。两个代理模型共享统一的布局与参数融合表征，使其能够同时利用剪力墙布局图、全局布局特征、截面材料参数和抗震设防条件。

进一步地，本文引入在线局部校准机制，以缓解全局代理模型在特定布局和局部搜索区域中的偏差。优化过程中产生的真实有限元分析结果被复用为局部校准样本：对于可行性代理模型，局部校准用于修正当前布局下的概率偏差，并支持保守筛选；对于钢筋用量代理模型，局部残差模型用于修正全局预测误差，使候选方案的材料造价排序更加贴近当前搜索区域。通过这种方式，代理模型在优化过程中不是静态使用，而是随着真实分析结果逐步适配当前设计问题。

在优化阶段，本文将全局代理模型和在线局部校准嵌入候选方案评价流程。候选方案首先经过可行性代理模型筛选，明显不可行的方案被跳过；其余方案根据钢筋用量预测和快速混凝土用量估计形成材料造价分数，并按优先级选择部分候选进入真实有限元分析。真实分析结果一方面用于更新优化算法，另一方面继续补充局部校准样本。最终最优方案仍然由真实有限元分析和规范校核确认，从而避免将代理模型误差直接转化为最终设计风险。

本文的主要贡献可以概括如下：

1. 构建了面向剪力墙结构设计优化的参数化建模、有限元分析和设计校核流程，并基于多布局、多设计条件样本形成代理模型训练数据。
2. 建立了统一的布局-参数代理模型框架，分别用于结构可行性保守筛选和钢筋用量预测，为优化过程中的候选筛选与造价预排序提供依据。
3. 提出了利用优化过程中已有有限元分析结果进行在线局部校准的方法，修正全局代理模型在当前布局和局部搜索区域中的概率偏差与钢筋用量残差。
4. 将校准后的代理模型嵌入结构优化算法，在保持最终真实有限元验证和规范校核的前提下，减少无效候选的有限元调用，提高剪力墙结构优化效率。

本文其余部分组织如下。第 2 节介绍校准代理辅助优化框架，包括问题定义、数据表征、全局代理模型和在线局部校准方法。第 3 节说明数据集、模型训练、优化基准和评价指标。第 4 节给出代理模型、局部校准和优化效率实验结果，并讨论方法适用性和局限性。第 5 节总结全文并展望后续研究方向。
