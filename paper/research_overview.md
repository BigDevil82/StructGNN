# 基于建筑空间图表示的条件化剪力墙布置生成研究

## Research Overview: Conditional Generation of Shear Wall Layouts Using Graph Neural Networks on Architectural Space Representations

---

## 一、研究背景与问题

### 1.1 工程背景

剪力墙结构是高层建筑抗震设计的核心承重体系。合理的剪力墙布置直接决定建筑的抗侧刚度、承载能力和经济性。传统的剪力墙设计依赖结构工程师根据规范和经验进行人工布置，这一过程存在以下痛点：

- **效率低下**：工程师需要反复调整布置方案并进行结构分析验证
- **方案单一**：受限于个人经验，难以探索更优的布置可能性
- **难以优化**：人工方法难以在满足规范的前提下兼顾经济性和性能

### 1.2 现有方法的局限性

近年来，研究者尝试利用深度学习方法自动化剪力墙布置预测，主要分为两类：

**基于图像的方法**：将建筑平面图作为图像输入，使用CNN预测剪力墙分布的热力图。这类方法存在明显缺陷：
- 无法显式学习建筑构件间的拓扑关系
- 模型参数量庞大，信息冗余严重
- 输出为像素级预测，需要后处理才能得到精确的墙体位置

**基于几何图元的GNN方法**：将墙体线段作为图的节点，构建几何邻接图。虽然引入了图结构，但也存在问题：
- 节点为构件级图元，无法捕捉建筑空间的功能语义
- 图规模与墙体数量成正比，计算复杂度高
- 需要额外进行梁布置预测，无法在统一框架内完成

### 1.3 研究目标

本研究旨在提出一种新的剪力墙布置预测方法，能够：
1. 从建筑空间层面学习剪力墙分布规律
2. 根据不同设计条件（抗震等级）生成差异化的布置方案
3. 在保证预测精度的同时，具有更好的可解释性和可扩展性

## 二、核心方法

### 2.1 基于房间的图表示（Room-based Graph Representation）

**核心思想**：与现有基于几何图元的方法不同，本研究以**建筑空间（房间）**作为图的节点，以房间间的**空间邻接关系**作为边。

**设计动机**：
- 剪力墙的布置本质上受建筑功能分区的约束——墙体位于房间边界
- 房间级抽象天然保留了建筑的空间语义
- 图规模与房间数量相关（通常10-30个），远小于构件级图
- 统一框架可直接扩展至梁布置预测（梁同样位于房间边界）

**节点特征（25维）**：
- **几何特征（9维）**：房间中心坐标(2)、面积(1)、宽高比(1)、边界框尺寸(4)、周长(1)
- **约束特征（16维）**：房间四条边（上、右、下、左）各自的可布置区域信息，每边4维（2段×2端点）

**边特征（8维）**：
- 共享边长度(1)、相对距离(2)、相对方位one-hot编码(4)、共享边比例(1)

**输出表示（16维向量）**：
- 每个房间输出一个16维向量，表示其四条边上的剪力墙分布
- 4条边 × 每边2段 × 每段2端点位置 = 16维
- 每个位置的值表示墙体占该半边长度的比例（0-1）

### 2.2 条件化GNN模型（Conditional GNN with FiLM）

**模型架构**：

```
输入: 节点特征(N×25) + 边特征(E×8) + 设计条件(1×3)
  ↓
节点编码器: Linear(25→256)
边编码器: Linear(8→256)
条件编码器: MLP(3→32)
  ↓
GATv2 Layer 1 + BatchNorm + FiLM + ReLU + Residual
GATv2 Layer 2 + BatchNorm + FiLM + ReLU + Residual
GATv2 Layer 3 + BatchNorm + FiLM + ReLU + Residual
  ↓
解码器: MLP(256→128→32)
  ↓
输出: 分类概率(N×16) + 回归比例(N×16)
```

**GATv2（Graph Attention Network v2）**：
- 使用图注意力机制动态学习邻居节点的重要性权重
- 相比原始GAT，GATv2具有更强的表达能力（动态注意力）
- 采用4头注意力机制捕捉多种邻接关系模式

**FiLM条件化机制（Feature-wise Linear Modulation）**：
- 将设计条件（抗震等级：低/中/高）编码为32维向量
- 在每个GATv2层后通过FiLM调制节点特征：`x' = x × (1 + γ) + β`
- γ和β由条件向量经线性变换得到
- 使模型能够根据不同条件生成差异化的预测

**双头输出设计**：
- **分类头**：预测每个位置是否存在剪力墙（二分类，Sigmoid激活）
- **回归头**：预测剪力墙的精确长度比例（连续值，Sigmoid归一化到0-1）
- 最终预测 = 分类概率 × 回归比例

### 2.3 双流训练策略（Dual-Stream Training）

**训练流程**：

**监督流（Supervised Stream）**：
- 使用真实建筑数据及其对应的设计条件
- 计算混合损失进行标准监督学习

**约束流（Constraint Stream）**：
- 对每个训练样本，随机生成一个"假条件"（与真实条件不同的抗震等级）
- 使用同一建筑在假条件下的预测，计算全局密度损失
- 强制模型在不同条件下产生不同密度的墙体分布

**设计动机**：
- 仅靠监督学习，模型可能忽略条件输入（条件信息被当作噪声）
- 假条件流显式要求：低等级→低密度，高等级→高密度
- 通过对比学习的思想，增强条件化生成的可控性

**训练细节**：
- 前20个epoch仅使用监督流进行预热（warmup）
- 之后逐步增加约束流的权重（从0.01线性增长至0.1）
- 防止早期训练不稳定

### 2.4 混合损失函数（Hybrid Loss Function）

**总损失组成**：
```
L_total = L_cls + 2×L_reg + 2×L_iou + 0.5×L_consistency + 0.05×L_density_real + w×L_density_fake
```

**各项损失**：

| 损失项 | 公式 | 作用 |
|--------|------|------|
| BCE分类损失 | BCE(pred_prob, gt_binary) | 学习墙体存在性 |
| MSE回归损失 | MSE(pred_ratio, gt_ratio) | 学习墙体精确长度（仅在有墙位置计算） |
| Vector IoU损失 | 1 - IoU(pred_vector, gt_vector) | 向量级重叠度优化 |
| 一致性损失 | MSE(src_edge_pred, dst_edge_pred) | 邻接房间共享边的预测一致性 |
| 全局密度损失 | MSE(avg_density_pred, target_density) | 条件化密度控制 |

**Vector IoU**：
- 将16维输出向量视为一维线段集合
- 计算预测向量与真实向量的交集/并集比
- 对剪力墙的位置和长度进行联合优化

## 三、实验验证

### 3.1 数据集

- 来源：真实高层住宅建筑CAD图纸
- 格式：DXF文件，包含房间边界和剪力墙标注
- 划分：训练集(70%) / 测试集(30%)
- 增广：6种几何变换（原图、水平翻转、垂直翻转、旋转90°/180°/270°）
- 训练方式：5折交叉验证

### 3.2 评估指标

**预测精度评估**：
- **Vector IoU**：16维向量的重叠度
- **Precision/Recall/F1**：墙体存在性的分类指标
- **MAE**：墙体长度比例的回归误差

**条件化生成评估（CGS - Conditional Generation Score）**：
- **密度一致性**：预测密度与条件目标密度的匹配程度
- **条件区分度**：不同条件下预测结果的差异性
- **空间均匀性**：墙体分布的空间合理性

### 3.3 消融实验

验证各核心组件的贡献：
- **Backbone对比**：GATv2 vs GCN vs GraphSAGE vs GIN
- **条件化方法**：FiLM vs Concat-Early vs Concat-Late vs None
- **损失函数**：各项损失的单独贡献
- **训练策略**：双流训练 vs 仅监督学习、Warmup vs 无Warmup

### 3.4 基线对比

与现有基于几何图元的GNN方法进行对比，验证房间级图表示的优势。

## 四、创新贡献

1. **房间级图表示**（Room-based Graph Representation）
   - 首次将建筑空间作为图的节点进行剪力墙预测
   - 相比几何图元方法，更好地保留空间语义，降低计算复杂度
   - 为扩展至梁柱布置提供统一框架

2. **条件化生成机制**（Conditional Generation with FiLM）
   - 引入FiLM机制实现设计条件的灵活控制
   - 使同一建筑能够根据不同抗震等级生成差异化方案

3. **双流训练策略**（Dual-Stream Training Strategy）
   - 通过假条件对比学习增强条件响应能力
   - 解决条件信息被忽略的问题

---

## 五、研究意义与展望

### 5.1 学术意义

- 提出了结构设计中图表示的新范式（空间级 vs 构件级）
- 将条件化生成的思想引入结构工程领域
- 为AI辅助建筑设计提供了可解释性更强的方法

### 5.2 工程价值

- 显著提升剪力墙布置方案生成效率
- 支持工程师快速探索不同设计条件下的布置可能
- 生成方案可直接用于后续结构分析验证

### 5.3 未来工作

- **更精细的条件控制**：使用连续的建筑高度、抗震烈度值替代粗糙分类
- **异形空间支持**：当前仅处理矩形房间，需扩展至L形、多边形空间
- **结构性能约束**：引入位移、应力等结构分析结果作为训练约束
