# Pipelines Skeleton

本目录是 `experiments/` 中“正式流程候选”部分的目标落点。

当前仅作为骨架存在，暂不承载实际实现代码，原因是：

- `case_study/` 仍有较多旧 import 依赖
- 直接移动文件会带来较高的遗漏风险
- 当前阶段优先建立迁移目标，而不是立即改物理路径

计划迁入的内容：

- `case_study/` 相关案例推理流程
- FEM 拓扑解析
- 外部建模软件桥接流程

当前已建立兼容包装目录：

- `case_study/`

在正式迁移前，新增的流程型代码应优先考虑是否直接放到这里，而不是继续堆到旧的 `case_study/` 中。
